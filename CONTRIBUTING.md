# Contributing

- To request an ontology or a new release, [open an issue](https://github.com/NeverBlink-OSS/ohi-index/issues/new?template=ontology-request.yml).
- To prepare a package and submit a pull request, follow the [contribution guide](https://ohi.dev/docs/guides/contributing-ontologies/).

Follow the [Code of Conduct](CODE_OF_CONDUCT.md).

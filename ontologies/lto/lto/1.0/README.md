Library Transaction Ontology, by Indian Statistical Institute. A FAIR-compliant metadata vocabulary (MV), the Library Transaction Ontology (LTO), is designed and developed for representing and managing library transaction data (LTD), including circulation, interlibrary loan, hold requests, and fiscal information.

FOG: File Ontology for Geometry formats, by Mathias Bonduel and others. The File Ontology for Geometry formats (FOG) describes meaningful relations towards geometry snippets in RDF literals, geometry files on relative or absolute URLs and ontology-based geometry descriptions.

IDS Information Model, by Sebastian Tramp and others. This ontology defines classes and properties for describing participants, infrastructure, data and services of the International Data Spaces (formerly known as Industrial Data Space). Vocabulary IRI: https://w3id.org/idsa/core

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/ids/versions/2020-08-18.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2020-08-18, which its link https://lov.linkeddata.es/dataset/lov/vocabs/ids/versions/2020-08-18.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 228 classes, 203 properties, 67 individuals in its own namespace, https://w3id.org/idsa/core/.
- The version is the one the file states.
- LOV tags: API, Catalogs, Contracts, Services.

'Configuration as Linked Data' ontology, by François-Paul Servant and others. Ontology for the description of customizable products. Vocabulary IRI: http://purl.org/configurationontology

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/cold/versions/2013-02-26.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2013-02-26, which its link https://lov.linkeddata.es/dataset/lov/vocabs/cold/versions/2013-02-26.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is stored in this folder, because it was changed, see below.

Notes:

- 8 classes, 20 properties in its own namespace, http://purl.org/configurationontology#.
- The file states no version, so the version is the date of LOV's copy.
- LOV tags: eBusiness.

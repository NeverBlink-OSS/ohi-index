Territorial Statistical Nomenclature Change Ontology, by Steamer. The TSN-Change ontology aims at describing changes that occured from one version of a Territorial Statistical Nomenclature (TSN) (i.e., partition of the territory) and its subsequent (e.g., change in territorial units boundaries to reflect an administrative reorganisation). Vocabulary IRI: http://purl.org/net/tsnchange#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/tsnc/versions/2017-05-15.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/tsnc/versions/2017-05-15.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 38 classes, 27 properties in its own namespace, http://purl.org/net/tsnchange#.
- The version is the one the file states.
- LOV tags: Geography, Geometry, Government, Metadata.

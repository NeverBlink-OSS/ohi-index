A vocabulary for jobs, by CTIC Foundation. This is a vocabulary for modeling jobs offer in Spain. Vocabulary IRI: http://purl.org/ctic/empleo/oferta

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/emp/versions/2013-09-03.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/emp/versions/2013-09-03.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

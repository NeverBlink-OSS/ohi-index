Dataset Catalog Vocabulary, by ctic. This vocabulary is used for modelling catalogs of datasets and its relationships with the datasets. Vocabulary IRI: http://purl.org/ctic/dcat#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/ds/versions/2011-11-05.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2011-11-05, which its link https://lov.linkeddata.es/dataset/lov/vocabs/ds/versions/2011-11-05.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 2 classes, 3 properties in its own namespace, http://purl.org/ctic/dcat#.
- The file states no version, so the version is the date of LOV's copy.
- LOV tags: Catalogs.

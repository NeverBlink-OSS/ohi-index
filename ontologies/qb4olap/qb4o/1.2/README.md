Vocabulary for publishing OLAP data cubes, by Lorena Etcheverry. This vocabulary allows to publish and operate with OLAP cubes in RDF. Vocabulary IRI: http://purl.org/qb4olap/cubes

Depends on `w3c/qb@2014`.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/qb4o/versions/2015-05-17.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2015-05-17, which its link https://lov.linkeddata.es/dataset/lov/vocabs/qb4o/versions/2015-05-17.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

The Geonames ontology, by Geonames.org. The Geonames ontology provides elements of description for geographical features defined in the geonames.org data base. Vocabulary IRI: http://www.geonames.org/ontology

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/gn/versions/2010-10-05.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2010-10-05, which its link https://lov.linkeddata.es/dataset/lov/vocabs/gn/versions/2010-10-05.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

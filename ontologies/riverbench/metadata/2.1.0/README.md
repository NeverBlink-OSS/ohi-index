RiverBench metadata, by RiverBench. Ontology for the metadata of RiverBench datasets, profiles and benchmark tasks. Ontology IRI: https://w3id.org/riverbench/schema/metadata

Depends on `stax/rdf-stax@1.1.0`, `w3c/dcat@3`.

Package created (its files downloaded or sources' hashes created) on 2026-10-23.
The ontology file is from https://github.com/RiverBench/schema/releases/download/v2.1.0/metadata.ttl.
The release download redirects to a signed URL that expires, so it cannot be a source.
The repository's `src/metadata.ttl` at `v2.1.0` is not the same file as the release asset.
So the file is stored in this folder.

Notes:

- Imports DCAT without a version; the dependency is `w3c/dcat@3`, the newest in the index.

RiverBench metadata, by RiverBench. Ontology for the metadata of RiverBench datasets, profiles and benchmark tasks. Ontology IRI: https://w3id.org/riverbench/schema/metadata

Depends on `w3c/dcat@3`.

Package created (its files downloaded or sources' hashes created) on 2026-10-29.
The ontology file is from https://github.com/RiverBench/schema/releases/download/v0.1.0/metadata.ttl.
The release download redirects to a signed URL that expires, so it cannot be a source.
The repository's `src/metadata.ttl` at `v0.1.0` is not the same file as the release asset.
So the file is stored in this folder.

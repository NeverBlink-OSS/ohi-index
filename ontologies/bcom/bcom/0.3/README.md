Building Concrete Monitoring Ontology (BCOM), by Chair of Computing in Engineering, Ruhr University Bochum. The Building Concrete Monitoring Ontology (BCOM) is defined for capturing information of concrete work, concrete curing and testing of concrete properties. Vocabulary IRI: https://w3id.org/bcom

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/bcom/versions/2021-07-26.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/bcom/versions/2021-07-26.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 8 classes, 58 properties in its own namespace, https://w3id.org/bcom#.
- The version is the one the file states.
- LOV tags: Industry.

Metadata4Ing: An ontology for describing the generation of research data within a scientific activity, by NFDI4Ing. Metadata4Ing defines classes and properties or reuses such classes and properties from other ontologies to describe research processes and research data management in NFDI4Ing. Vocabulary IRI: http://w3id.org/nfdi4ing/metadata4ing#

Depends on no other package.

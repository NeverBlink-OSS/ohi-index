The Linked Earth Ontology, by Nick McKay and others. The Linked Earth Ontology aims to provide a common vocabulary for annotating paleoclimatology data. Vocabulary IRI: http://linked.earth/ontology#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/earth/versions/2016-06-13.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/earth/versions/2016-06-13.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.

RDF Logging Ontology, by Sebastian Hellmann. This is a helper ontology for NIF 2.0 to be able to log errors and warning messages. Vocabulary IRI: http://persistence.uni-leipzig.org/nlp2rdf/ontologies/rlog#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/rlog/versions/2015-04-01.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/rlog/versions/2015-04-01.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 3 classes, 8 properties, 8 individuals in its own namespace, http://persistence.uni-leipzig.org/nlp2rdf/ontologies/rlog#.
- The version is the one the file states.
- LOV tags: API.

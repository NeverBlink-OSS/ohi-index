Comic Book Ontology, by Sean Petiya. A metadata vocabulary for describing comic books and comic book collections. Vocabulary IRI: http://comicmeta.org/cbo/

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/cbo/versions/2015-12-05.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2015-12-05, which its link https://lov.linkeddata.es/dataset/lov/vocabs/cbo/versions/2015-12-05.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 56 classes, 127 properties in its own namespace, http://comicmeta.org/cbo/.
- The version is the one the file states.
- LOV tags: Image, Metadata.

ELSEWeb Lifemapper Ontology, by ELSEWeb Team. The ELSEWeb Lifemapper ontology provides classes for describing biodiversity modelling services provided by Lifemapper. Vocabulary IRI: http://ontology.cybershare.utep.edu/ELSEWeb/elseweb-edac.owl

Depends on `utep/lsweb@1.2`, `utep/edac@1.2`, `utep/lswpm@1.2`, `utep/lswmo@1.2`.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/lslife/versions/2015-09-24.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/lslife/versions/2015-09-24.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

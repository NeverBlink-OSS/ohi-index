Common Core Ontologies, by CUBRC, Inc. A stand-alone file containing the eleven mid-level Common Core Ontologies plus BFO. Provided for use-cases where one file representing a specific release of CCO and its imports is desirable. Ontology IRI: https://www.commoncoreontologies.org/CommonCoreOntologiesMerged

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-20.
The ontology file is from https://github.com/CommonCoreOntology/CommonCoreOntologies/blob/v2.0-2024-11-06/src/cco-merged/CommonCoreOntologiesMerged.ttl.
The file at the release tag `v2.0-2024-11-06` of CommonCoreOntology/CommonCoreOntologies.
The file is a remote source.

Notes:

- 1,385 classes, 225 object properties, 11 datatype properties, 24 annotation properties, 350 individuals in its own namespace, https://www.commoncoreontologies.org/.
- The version is the one the file states.
- The BFO terms CCO uses are copied into the file, so it has no imports.
- The eleven CCO modules (`AgentOntology.ttl` and the others) and `AllCoreOntology.ttl`, which imports them, hold the same content as separate files.
- Bioregistry prefix `commoncoreontology`.

Common Core Ontologies, by CUBRC, Inc. A stand-alone file containing the eleven mid-level Common Core Ontologies plus BFO. Provided for use-cases where one file representing a specific release of CCO and its imports is desirable. Ontology IRI: http://www.ontologyrepository.com/CommonCoreOntologies/Mid/MergedAllCoreOntology

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-20.
The ontology file is from https://github.com/CommonCoreOntology/CommonCoreOntologies/blob/v1.6-2024-09-26/src/cco-merged/CommonCoreOntologiesMerged.ttl.
The file at the release tag `v1.6-2024-09-26` of CommonCoreOntology/CommonCoreOntologies.
The file is a remote source.

Notes:

- 1,384 classes, 225 object properties, 11 datatype properties, 28 annotation properties, 350 individuals in its own namespace, http://www.ontologyrepository.com/CommonCoreOntologies/.
- The version is the one the file states.
- The BFO terms CCO uses are copied into the file, so it has no imports.
- The eleven CCO modules (`AgentOntology.ttl` and the others) and `AllCoreOntology.ttl`, which imports them, hold the same content as separate files.
- Bioregistry prefix `commoncoreontology`.

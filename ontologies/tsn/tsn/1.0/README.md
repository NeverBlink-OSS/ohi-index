Territorial Statistical Nomenclature Ontology, by Steamer. This RDF ontology allows describing any Territorial Statistical Nomenclature (TSN) (i.e., partition of the territory) used as a support to socio-economic data (statistical data that describe territory in terms of population, unemployement rate, transport access, etc.). Vocabulary IRI: http://purl.org/net/tsn#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/tsn/versions/2017-01-31.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/tsn/versions/2017-01-31.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 11 classes, 20 properties in its own namespace, http://purl.org/net/tsn#.
- The version is the one the file states.
- LOV tags: Geography, Geometry, Government.

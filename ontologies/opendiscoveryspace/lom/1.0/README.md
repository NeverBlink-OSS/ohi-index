Learning Object Metadata Ontology, by Open Discovery Space project. An ontology and vocabulary used for exposing IEEE LOM, a metadata standard for educational contents, as Linked Data. Vocabulary IRI: http://data.opendiscoveryspace.eu/lom_ontology_ods.owl#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/lom/versions/2015-03-30.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/lom/versions/2015-03-30.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 17 classes, 70 properties, 1 individual in its own namespace, http://data.opendiscoveryspace.eu/lom_ontology_ods.owl#.
- The version is the one the file states.
- LOV tags: Metadata.

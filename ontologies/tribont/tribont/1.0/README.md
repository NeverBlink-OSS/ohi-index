TribOnt ontology, by IK4-TEKNIKER. The goal is to represent the tribological experiments by relaying on the representation included in the core,, sample and equipment modules. Vocabulary IRI: https://w3id.org/tribont

Depends on `tribont/tribont-equipment@1.0`, `tribont/tribont-sample@1.0`.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/tribont/versions/2023-06-02.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/tribont/versions/2023-06-02.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Core module, by IK4-TEKNIKER. The goal of this module is to represent the common classes, and object and data properties included in two or more modules of the TribOnt ontology. Vocabulary IRI: https://w3id.org/tribont/core

Depends on `ischaracterisedby/icb@1.0`.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/tribont-core/versions/2023-05-30.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/tribont-core/versions/2023-05-30.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 208 classes, 22 properties, 234 individuals in its own namespace, https://w3id.org/tribont/core#.
- The version is the one the file states.

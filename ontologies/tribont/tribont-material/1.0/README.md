Material module, by IK4-TEKNIKER. The goal of this module is to represent the materials that can be involved in the tribological experiments as part of the tested samples. Vocabulary IRI: https://w3id.org/tribont/material

Depends on `tribont/tribont-core@1.0`.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/tribont-material/versions/2023-06-02.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/tribont-material/versions/2023-06-02.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

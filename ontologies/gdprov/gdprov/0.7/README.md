The GDPR Provenance ontology, by ADAPT Centre, Trinity College. GDPRov is an OWL2 ontology to express provenance metadata of consent and data lifecycles towards documenting compliance for GDPR. Vocabulary IRI: https://w3id.org/GDPRov

Depends on `p-plan/p-plan@1.3`, `w3c/prov-o@2013`.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/gdprov/versions/2018-04-06.n3.

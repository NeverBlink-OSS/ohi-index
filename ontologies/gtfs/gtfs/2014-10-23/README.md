General Transit Feed Specification, by Andrew Byrd and others. This ontology is a translation of the General Transit Feed Specification towards URIs. Vocabulary IRI: http://vocab.gtfs.org/terms#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/gtfs/versions/2014-10-23.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2014-10-23, which its link https://lov.linkeddata.es/dataset/lov/vocabs/gtfs/versions/2014-10-23.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Linked Datex II, by Pieter Colpaert. This document gives URIs to all terms used within Datex II. Vocabulary IRI: http://vocab.datex.org/terms#ontology

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/datex/versions/2016-06-13.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/datex/versions/2016-06-13.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 389 classes, 1,336 properties, 409 individuals in its own namespace, http://vocab.datex.org/terms#.
- The file states no version, so the version is the date of LOV's copy.

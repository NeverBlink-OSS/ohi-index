DSNotify Eventsets: A vocabulary for change events in linked data sources, by Bernhard Haslhofer and others. DSNotify Eventsets is a vocabulary for events that change resources in linked data sources. Vocabulary IRI: http://purl.org/dsnotify/vocab/eventset/

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/dsn/versions/2013-11-29.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2013-11-29, which its link https://lov.linkeddata.es/dataset/lov/vocabs/dsn/versions/2013-11-29.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is stored in this folder, because it was changed, see below.

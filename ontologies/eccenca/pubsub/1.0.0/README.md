Eccenca Publish-Subscribe Vocabulary, by eccenca GmbH. The eccenca Publish-Subscribe Vocabulary defines concepts and relations to create statements about publishers, subscribers and their subscriptions in a Publish-Subscribe environment based on the PubSubHubbub Core 0.4 specification. Vocabulary IRI: https://vocab.eccenca.com/pubsub/

Depends on no other package.

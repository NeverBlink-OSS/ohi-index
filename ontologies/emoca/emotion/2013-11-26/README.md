Emotion Ontology for Context Awareness, by Institut National de Recherche en Informatique et en Automatique. EmOCA is used to contextualize dimensionnal emotion and to categorize it for human readability. Vocabulary IRI: http://ns.inria.fr/emoca

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/emotion/versions/2013-11-26.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/emotion/versions/2013-11-26.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 16 classes, 9 properties in its own namespace, http://ns.inria.fr/emoca#.
- The version is the one the file states.
- LOV tags: People.

Linked Science Core Vocabulary, by Tomi Kauppinen and others. LSC, the Linked Science Core Vocabulary, is a lightweight vocabulary providing terms to enable publishers and researchers to relate things in science to time, space, and themes. Vocabulary IRI: http://linkedscience.org/lsc/ns#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/lsc/versions/2011-11-29.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/lsc/versions/2011-11-29.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is stored in this folder, because it was changed, see below.

Notes:

- 7 classes, 17 properties in its own namespace, http://linkedscience.org/lsc/ns#.
- The file states no version, so the version is the date of LOV's copy.
- LOV tags: Methods.

Ontology of coordinates reference systems, by Institut National de l'Information Géographique et Forestière. Codes for describing coordinates reference systems consistently with ISO TC/211. Vocabulary IRI: http://data.ign.fr/def/ignf

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/ignf/versions/2015-05-05.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2015-05-05, which its link https://lov.linkeddata.es/dataset/lov/vocabs/ignf/versions/2015-05-05.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.

An ontology for describing territory elements an infrastructure at French Mapping Agency, by Institut National de l'Information Géographique et Forestière. This ontology reuses the legacy schema of BDTOPO(IGN) and aims at covering the topographic entities and administrative boundaries of the French national territory. Vocabulary IRI: http://data.ign.fr/def/topo#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/topo/versions/2014-04-12.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2014-04-12, which its link https://lov.linkeddata.es/dataset/lov/vocabs/topo/versions/2014-04-12.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 47 classes, 52 properties in its own namespace, http://data.ign.fr/def/topo#.
- The version is the one the file states.
- LOV tags: Geography.

Ontology of administrative units at IGN-France, by Institut National de l'Information Géographique et Forestière. An ontology describing the administrative divisions in France. Vocabulary IRI: http://data.ign.fr/def/geofla

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/geofla/versions/2014-08-22.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2014-08-22, which its link https://lov.linkeddata.es/dataset/lov/vocabs/geofla/versions/2014-08-22.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 7 classes, 16 properties in its own namespace, http://data.ign.fr/def/geofla#.
- The version is the one the file states.

Algorithm Knowledge Graph Ontology, by Christian Himpe (https://orcid.org/0000-0003-2194-6754). This vocabulary and grammar defines which types of objects are admissible to the MathAlgoDB - the algorithm knowledge graph - and by which properties they can relate.

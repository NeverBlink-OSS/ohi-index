The IMGpedia Ontology, by Sebastián Ferrada and others. The IMGpedia Ontology provides terms to describe descriptors and similarity relations between images. Vocabulary IRI: http://njh.me/

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/imo/versions/2018-01-12.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/imo/versions/2018-01-12.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 6 classes, 11 properties in its own namespace, http://imgpedia.dcc.uchile.cl/ontology#.
- The file states no version, so the version is the date of LOV's copy.
- LOV tags: Image.

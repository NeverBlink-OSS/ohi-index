Semantic Web Rule Language, by W3C. OWL definition of the RDF Concrete Syntax for the Semantic Web Rule Language. Vocabulary IRI: http://www.w3.org/2003/11/swrl

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02; source changed on 2026-11-03.
The ontology file is from https://www.w3.org/submissions/2004/SUBM-SWRL-20040521/swrl.owl, the OWL ontology of the W3C Member Submission of 21 May 2004 (https://www.w3.org/submissions/SWRL/). The submission's current link, https://www.w3.org/submissions/SWRL/swrl.owl, serves the same file.
The file is a remote source.

Notes:

- 12 classes, 8 object properties and 1 property in its own namespace, http://www.w3.org/2003/11/swrl#.
- The version is the date of the submission, which the file's `owl:versionInfo` (`$Id: swrl.owl,v 1.1 2004/05/21 …`) states too.
- The submission publishes two files: "An RDF Schema for SWRL is swrl.rdf. An OWL ontology for SWRL is swrl.owl", and calls the OWL ontology the more complete of the two. The package first used LOV's copy (https://lov.linkeddata.es/dataset/vocabs/swrl/versions/2004-05-21.n3, 11 classes and 9 properties as RDFS), which matches the RDF Schema; it now uses the OWL ontology.
- The file has a DOCTYPE with internal entities only, and declares its own `xml:base` (`http://www.w3.org/2003/11/swrl`).
- LOV tags: Vocabularies.

OntoAvida: ontology for Avida digital evolution platform, by OBO Foundry. OntoAvida develops an integrated vocabulary for the description of the most widely-used computational approach for studying evolution using digital organisms (i.e., self-replicating computer programs that evolve within a user-defined computational environment). Ontology IRI: http://purl.obolibrary.org/obo/ontoavida.owl

The IoTTaxonomy-lite Taxonomy, by Elsaleh Tarek and others. The IoT-Taxonomy-lite is adapted from M3-lite taxonomy. Vocabulary IRI: http://purl.org/iot/vocab/iot-taxonomy-lite#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/iottaxolite/versions/2019-09-07.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/iottaxolite/versions/2019-09-07.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 470 classes in its own namespace, http://purl.org/iot/vocab/iot-taxonomy-lite#.
- The version is the one the file states.
- LOV tags: IoT.

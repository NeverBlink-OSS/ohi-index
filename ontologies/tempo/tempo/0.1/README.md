TempO - Temporal Ontology, by Sebastian Freundt. In a typical (uni)temporal data model every resource's appearance (and disappearance) is being tracked. Vocabulary IRI: http://purl.org/tempo

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/tempo/versions/2022-08-20.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/tempo/versions/2022-08-20.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 1 class, 5 properties in its own namespace, http://purl.org/tempo/.
- The version is the one the file states.

MARC Code List for Relators, by Library of Congress. MARC relators are defined as both RDF properties and SKOS concepts. Vocabulary IRI: http://id.loc.gov/vocabulary/relators

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/mrel/versions/2014-06-03.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2014-06-03, which its link https://lov.linkeddata.es/dataset/lov/vocabs/mrel/versions/2014-06-03.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 268 properties in its own namespace, http://id.loc.gov/vocabulary/relators/.
- The file states no version, so the version is the date of LOV's copy.

BEVON: Beverage Ontology, by James G. Kim. Beverage Ontology is a Web vocabulary for describing beverages, mainly alcoholic. Vocabulary IRI: http://rdfs.co/bevon/0.7

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/bevon/versions/2015-01-11.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2015-01-11, which its link https://lov.linkeddata.es/dataset/lov/vocabs/bevon/versions/2015-01-11.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Process Execution ontology, by Maxime Lefrançois. The process execution ontology is a proposal for a simple extension of both the [W3C Semantic Sensor Network](https://www.w3.org/TR/vocab-ssn/) and the [Semantic Actuator Network](https://www.irit.fr/recherches/MELODI/ontologies/SAN.owl) ontology cores. Vocabulary IRI: https://w3id.org/pep/

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/pep/versions/2016-07-01.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/pep/versions/2016-07-01.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 3 classes, 10 properties in its own namespace, https://w3id.org/pep/.
- The version is the one the file states.
- LOV tags: Industry, Methods, Services.

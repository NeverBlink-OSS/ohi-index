SPITFIRE Ontology, by Myriam Leggieri and others. TheSPITFIRE Ontology (spt) is based on the alignment among Dolce+DnS Ultralite(dul), the W3C Semantic Sensor Network ontology (ssn) and the Event Model-F ontology (event). Vocabulary IRI: http://spitfire-project.eu/ontology/ns

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/spt/versions/2013-11-06.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's version of 2013-11-06, which its link https://lov.linkeddata.es/dataset/lov/vocabs/spt/versions/2013-11-06.n3 redirects to. No URL of the publisher serves that version without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 48 classes, 74 properties in its own namespace, http://spitfire-project.eu/ontology/ns/.
- The file states no version, so the version is the date of LOV's copy.
- LOV tags: IoT, Methods.

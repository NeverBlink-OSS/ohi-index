VIR - Visual Representation ontology, by Nicola Carboni. This ontology, called VIR, is an extension of CIDOC-CRM created to sustain propositions on the nature of visual elements and permit these descriptions to be published on the Web. Vocabulary IRI: http://w3id.org/vir#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/vir/versions/2019-02-26.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/vir/versions/2019-02-26.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.

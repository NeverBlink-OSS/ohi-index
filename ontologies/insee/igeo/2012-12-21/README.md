French Statistical ontology for geolocation, by INSEE. Ontology describing geographic entities as seen by the French Statistical Institute. Vocabulary IRI: http://rdf.insee.fr/def/geo

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/igeo/versions/2015-01-11.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/igeo/versions/2015-01-11.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 48 classes, 44 properties in its own namespace, http://rdf.insee.fr/def/geo#.
- The version is the one the file states.
- LOV tags: Geography.

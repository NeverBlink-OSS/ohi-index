Demographic ontology from the French Statistics Institute, by INSEE. Ontology with classes and properties used for demography, mostly in the census of the population. Vocabulary IRI: http://rdf.insee.fr/def/demo

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/idemo/versions/2012-12-26.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/idemo/versions/2012-12-26.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 1 class, 5 properties in its own namespace, http://rdf.insee.fr/def/demo#.
- The version is the one the file states.
- LOV tags: Methods.

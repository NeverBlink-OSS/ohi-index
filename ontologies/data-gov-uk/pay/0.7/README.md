Payments ontology, by Jeni Tennison and others. Vocabulary for representing payments, such as government expenditures, using the data cube representation. Vocabulary IRI: http://reference.data.gov.uk/def/payment#

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/pay/versions/2010-11-16.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/pay/versions/2010-11-16.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

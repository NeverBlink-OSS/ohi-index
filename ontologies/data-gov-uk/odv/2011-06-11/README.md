Organogram Data Vocabulary, by Jeni Tennison. Extension of data cube for civil service junior posts. Vocabulary IRI: http://reference.data.gov.uk/def/organogram

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/odv/versions/2011-06-11.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/odv/versions/2011-06-11.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 11 properties in its own namespace, http://reference.data.gov.uk/def/organogram/.
- The file states no version, so the version is the date of LOV's copy.
- LOV tags: Methods.

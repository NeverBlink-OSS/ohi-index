MobiVoc: Open Mobility Vocabulary, by eccenca GmbH. Our goal is to significantly improve the data mobility between all stakeholders by providing a standardized vocabulary using Semantic Web technologies and ontologies. Vocabulary IRI: http://schema.mobivoc.org/

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/mv/versions/2018-01-18.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/mv/versions/2018-01-18.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

Notes:

- 23 classes, 56 properties in its own namespace, http://schema.mobivoc.org/.
- The version is the one the file states.

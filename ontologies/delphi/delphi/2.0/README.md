Project Delphi: Probabilistic Knowledge Graph Ontology for Frontier Science, by Project Delphi / Science Oracle (scienceoracle.com). The vocabulary (T-Box) used by Project Delphi / Science Oracle (scienceoracle.com) to represent scientific papers, the propositions drawn from them or synthesised across them, the economic predictions attached to those propositions, and the probabilistic assessments that a panel of independent software agents assign to them. Vocabulary IRI: https://w3id.org/delphi/ontology/

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04, on request.
The ontology file is from https://raw.githubusercontent.com/fractastical/project-delphi-ontology/v2.0/delphi.ttl, the tag `v2.0` (commit `fe39dff`) of https://github.com/fractastical/project-delphi-ontology.
The tag is fixed, so the URL keeps serving this version.
https://w3id.org/delphi/ontology and its version IRI https://w3id.org/delphi/ontology/2.0 answer 404: the w3id redirect is not registered.
The file is a remote source.

Notes:

- 13 classes, 8 object properties, 24 datatype properties, 1 datatype; 4 terms `owl:deprecated` (`Model`, `Paper`, `assessedBy`, `derivedFromPaper`) in its own namespace, https://w3id.org/delphi/ontology/.
- The version is the one the file states (`owl:versionInfo`, `owl:versionIRI`), the same as the tag.
- No `owl:imports`. The file maps its terms to the earlier namespace https://w3id.org/probknow/ontology/ with `owl:equivalentClass` and `owl:equivalentProperty`, and uses PROV-O, SKOS, Dublin Core Terms, CiTO, FaBiO and the Nanopublication schema without importing them.
- Keywords picked by hand: the repository has no topics and no registry lists it.
- The default branch `main` has changed `delphi.ttl` since the tag (dataset convention, 2026-10-30) and still states 2.0; that is no release, so the tag's file is taken.

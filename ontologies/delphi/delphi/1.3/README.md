Project Delphi: Probabilistic Knowledge Graph Ontology for Frontier Science, by Project Delphi / Science Oracle (scienceoracle.com). The vocabulary (T-Box) used by Project Delphi / Science Oracle (scienceoracle.com) to represent scientific papers, the discrete claims extracted from them, the hypotheses those claims cluster into, the economic predictions attached to hypotheses, and the probabilistic assessments that a panel of independent models assign to each claim. Vocabulary IRI: https://w3id.org/delphi/ontology/

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-04, on request.
The ontology file is from https://raw.githubusercontent.com/fractastical/project-delphi-ontology/v1.3/probknow.ttl, the tag `v1.3` (commit `527cff6`) of https://github.com/fractastical/project-delphi-ontology.
The tag is fixed, so the URL keeps serving this version.
https://w3id.org/delphi/ontology and its version IRI https://w3id.org/delphi/ontology/1.3 answer 404: the w3id redirect is not registered.
The file is a remote source.

Notes:

- 12 classes, 7 object properties, 24 datatype properties, 1 datatype in its own namespace, https://w3id.org/delphi/ontology/.
- The version is the one the file states (`owl:versionInfo`, `owl:versionIRI`), the same as the tag.
- No `owl:imports`. The file maps its terms to the earlier namespace https://w3id.org/probknow/ontology/ with `owl:equivalentClass` and `owl:equivalentProperty`, and uses PROV-O, SKOS, Dublin Core Terms, CiTO, FaBiO and the Nanopublication schema without importing them.
- Keywords picked by hand: the repository has no topics and no registry lists it.
- Upstream renamed the file `delphi.ttl` in 2.0; this version keeps its name at the tag, `probknow.ttl`.
- Terms use the prefix `pk:` for https://w3id.org/delphi/ontology/ (`delphi:` from 2.0).

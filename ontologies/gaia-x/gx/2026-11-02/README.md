Gaia-X Trust Framework Ontology, by gaia-x. The Gaia-X ontology defines classes and properties for describing participants, service offerings, resources, and compliance credentials within the Gaia-X federated data infrastructure ecosystem. Ontology IRI: https://w3id.org/gaia-x/development#gaia-x.owl.ttl

Depends on no other package.

That URL serves the current version, so it changes with the next one.

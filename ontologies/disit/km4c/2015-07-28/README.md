km4city, the DISIT Knowledge Model for City and Mobility, by DISIT Lab. A Knowledge Model to describe a smart city, that interconnect data from infomobility service, Open Data and other source. Vocabulary IRI: http://www.disit.org/km4city/schema

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-11-02.
The ontology file is from https://lov.linkeddata.es/dataset/vocabs/km4c/versions/2015-07-28.n3.
That is the copy Linked Open Vocabularies (LOV) keeps of the vocabulary's newest version there, which its link https://lov.linkeddata.es/dataset/lov/vocabs/km4c/versions/2015-07-28.n3 redirects to. No URL of the publisher serves the file without a redirect, so LOV's copy is used.
The file is a remote source.

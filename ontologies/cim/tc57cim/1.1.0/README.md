IEC Common Information Model, by Netbeheer Nederland. IEC TC57 CIM for power system and electricity grid data, as a LinkML schema generated from the official Sparx EA UML project. Schema id: https://cim.ucaiug.io/ns#TC57CIM

Depends on no other package.

Package created (its files downloaded or sources' hashes created) on 2026-10-30.
The ontology file is from https://github.com/netbeheernederland/tc57cim/releases/download/v1.1.0/im_tc57cim.schema.linkml.yml, the asset of release `v1.1.0` (2025-07-16).
The release download redirects to a signed URL that expires, so it cannot be a source.
The repository's `information_models/im_tc57cim.schema.linkml.yml` at `v1.1.0` is not the same file as the release asset: it has no `version`.
So the file is stored in this folder.
